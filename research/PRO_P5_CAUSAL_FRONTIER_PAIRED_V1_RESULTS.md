# P5 Causal Frontier Paired V1: Diagnostic Result

## Decision

P5-v1 is not an effectiveness experiment. None of its three pairs produced two
measurement-eligible terminal outcomes, so flat-versus-causal success, closure, and
efficiency deltas are not identifiable. The preregistered proceed rule failed and all six
episodes are excluded from future success tables.

The batch remains valuable because it falsified three measurement assumptions before any
fresh Dev case was consumed. Three episodes ended in dependency-acquisition read timeouts,
two ended when host auditing followed a container-only virtual-environment interpreter,
and one candidate used shell control flow that prevented the import probe from running.

## Three-Layer Diagnosis

**Observation.** Network failures must be censored rather than scored. A zero shell exit
does not prove that fixed postconditions ran. Repository effect auditing must reason about
container-created symlinks without resolving them against the host filesystem.

**Constraint.** V1 retired runtime roots when the next candidate did not repeat the same
error. Under partial observability, silence is not disconfirmation. A root can leave the
frontier only after a newer fact from the relevant verifier channel proves it resolved.
V1 also lacked an exact record of the frontier shown to the model, preventing faithful
posthoc attribution.

**Operation.** The open action space should remain unrestricted, but every candidate must
return control to the verifier. This is an execution contract, not a closed operation
vocabulary.

## Mechanism Signal

The signal is promising but deliberately not scored. On LangGraph, flat feedback first
led to Rust and maturin repairs and reached a verified compatible Python runtime only at
candidate 5. After causal candidate 1 exposed the PyO3 frontier, candidate 2 explicitly
identified Python 3.13 versus PyO3's 3.12 maximum and selected Python 3.12. Nonebot2
independently reproduced the same next-candidate response with a Python 3.12 conda
environment. Both treatment runs were later censored, so these observations show only
that a strong model can consume the representation.

## V2 Boundary

V2 changes only the smallest generic measurement semantics: persistent roots, mandatory
candidate completion, host-safe virtual-environment auditing, and exact model-projection
hashes. The model, verifier goal, open-program interface, candidate retention, case set,
and terminal-only Official evaluator boundary remain fixed. V1 and V2 outcomes must never
be pooled.
