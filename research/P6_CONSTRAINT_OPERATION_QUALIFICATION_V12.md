# P6 Constraint-Operation Qualification V12

## Question

Does frozen EnvSolve v16 improve natural terminal reach over the matched free-form
operation ablation on fresh development repositories, and does its new negative
operation state activate without over-pruning alternatives?

V12 is development qualification, not leaderboard evidence. It uses five new paired
identities from the 141 identities untouched after Q11. Selection is deterministic,
metadata-only, and forbidden until the DGX Spark host passes the preregistered gate.

## Frozen Contrast

Both methods receive the same repository and base-runtime observations, model,
primitive limits, raw execution feedback, Typed Replay IR v8 action provenance, and
Python verifier v6. The treatment receives the constraint operation plan and Guard
v4. The ablation remains free-form and cannot consume the typed operation state or
guard.

This is the paper's broad system contrast. It does not isolate negative operation
state as a single causal component. V12 may establish whether that mechanism is used
inside the full system; a dedicated component ablation is still required for a causal
component claim.

## Host Gate

Before case selection, the Spark must use a clean revision satisfying the frozen hash
chain, verify Harness v31 as `valid=true`, pass the full `410 passed, 1 skipped`
regression and the real Docker integration, match the frozen EnvBench revision, and
complete a case-free provider probe. A host failure consumes no case. Any frozen-file
change requires a new freeze and superseding preregistration before selection.

## Outcomes

The primary system outcome uses only scientifically eligible pairs where both methods
produce Boolean Official outcomes. At least two such pairs are required for a paired
comparison. Otherwise V12 reports terminal-reach insufficiency and failure
decomposition only.

Mechanism utilization is counted only when treatment first admits a hard
`operation/feasible=false` fact and later receives the same command in the same
relevant typed prefix context. Guard rejection must occur before environment
allocation. Admission without a later proposal is not a guard opportunity; zero
triggers means unexercised, with no case replacement or repository search.

## Integrity

Q1-Q11 identities remain consumed for effectiveness. Canary-20 and Official-Test-100
remain uninspected. Official evaluator feedback is post-episode only, no cross-case
memory is enabled, and no repository-specific rule may be added after selection.
Interruption and infrastructure outcomes follow the frozen censoring rules and never
overwrite an existing run.

The machine-readable preregistration is
`experiments/validations/p6_operation_qualification_v12_preregistration.json`.
